# STM32: PLL и таймеры

Учебный проект на STM32 HAL, созданный с помощью STM32CubeMX. В проекте я разобрался с настройкой системной тактовой частоты через PLL и основами работы с таймерами, включая режим Input Capture.

## Что изучил

- как настраивать PLL и как параметры настройки PLL влияют на тактовые частоты;
- основы настройки таймера в режиме Input Capture и работы с прерываниями таймера;
- как STM32CubeMX генерирует код инициализации периферии;
