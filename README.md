# STM32: PLL и таймеры

Учебный проект на STM32 HAL, созданный с помощью STM32CubeMX. В проекте я разобрался с настройкой системной тактовой частоты через PLL и основами работы с таймерами, включая режим Input Capture.

Сейчас проект измеряет частоту внешнего сигнала на входе TIM2 и отправляет результат через UART. Это пока учебный вариант, поэтому измерения и обработку редких/шумных сигналов ещё можно улучшать.

## Что изучил

- как настраивать PLL и как параметры настройки PLL влияют на тактовые частоты;
- основы настройки таймера в режиме Input Capture и работы с прерываниями таймера;
- как STM32CubeMX генерирует код инициализации периферии;
- как передавать текст по UART и выводить измеренное значение в Serial Monitor.

## Как это работает

TIM2 фиксирует значение счётчика на каждом восходящем фронте сигнала. По разнице между двумя захватами рассчитывается частота. Результат отправляется через USART2.

В проекте сейчас настроены:

- системная частота 50 МГц через PLL;
- TIM2, канал 1, вход захвата — PA0;
- USART2, скорость 115200 бод, формат 8N1;
- передача UART через PA2 (TX). Для приёма данных используется PA3 (RX).

Для просмотра результата подключи USB-UART адаптер: RX адаптера к PA2, GND к GND. В Serial Monitor выбери соответствующий порт и скорость 115200. Чтобы получить измерение, на PA0 должен поступать сигнал с логическими уровнями, совместимыми с STM32.

## Сборка

Для сборки нужны CMake, Ninja и `arm-none-eabi-gcc`.

```sh
cmake --preset Debug
cmake --build --preset Debug
```

Прошивка собирается в `build/Debug`.
